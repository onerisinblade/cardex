# Cardex

Мини-приложение для интервального повторения в формате флэш-карточек.

## Что есть

- новые пользователи стартуют без готовых колод;
- старые пользовательские колоды сохраняются в браузере;
- старую колоду с интегралами теперь можно удалить как обычную;
- колоды;
- карточки вопрос/ответ;
- поле «Пояснение» для текстовых колод;
- переносы строк в вопросе, ответе и пояснении;
- импорт `.txt`;
- экспорт выбранной колоды в `.txt`;
- светлая/тёмная тема;
- перемешивание без повторов: карточка не повторяется, пока не пройдёт весь круг;
- сохранение в браузере через localStorage.

## Импорт

Формат файла:

```txt
Вопрос | Ответ | Пояснение
Вопрос | Ответ
```

Третье поле необязательное. Если в карточке есть переносы строк, экспорт сохранит их как `\n`, а импорт восстановит обратно.
